Events and user groups

Apache Hop cares deeply about its community. Local user groups and events — meetups, hackathons, webinars, brainstorms — are how people meet each other and share what they have built. Find one near you, or start your own.

User groups

Ongoing groups, each in its own language and time zone.

  • 3Hx - Apache Hop Hot Hop Hangouts
  • Hop User Group Italia
  • Apache Hop em Português no Telegram
  • 日本Apache Hop ユーザーグループ (Apache Hop User Group Japan)

Upcoming

Nothing scheduled at the moment. If you are planning something, announce it on the users mailing list and it will appear here.

Add your own event

An event can be almost anything: a local user group meeting, an online hackathon, a brainstorm, a talk at a conference. To get yours listed, send the name, a short description, the date and time, the language and a registration link to the users mailing list.

Announce an eventSubscribe to users@

Recordings are welcome on the Hop YouTube channel, and get linked from the list below once published.
